# minipulator

ROS 2 Jazzy-пакет для настольного манипулятора на шести сервах, которым
управляет Arduino Nano по USB. Сервоприводы без обратной связи. Планирование движение в MoveIt. Для работы с роботом используется веб-интерфейс (ручное управление, создание, сохранение и запуск программ)

> English version of this README: [`instructions/README_EN.md`](instructions/README_EN.md).

## Оборудование

| Компонент | Примечание |
| --- | --- |
| 5 сервоприводов руки + 1 сервопривод захвата | TD-8120MG, диапазон 180° |
| Arduino Nano (ATmega328P) | USB-мост CH340, VID `1a86`, PID `7523` |
| Питание сервов | 5–6 В с запасом по току; общая земля с Nano |
| ПК | Ubuntu 24.04 с ROS 2 Jazzy |

Сигнальные пины сервоприводов — D4–D9 (суставы 1–5, затем захват).

## Возможности

- Планировщик реализован через MoveIt 2: OMPL, KDL, position-only IK.
- Общение с нижним уровнем (arduno nano) по серийному порту.
- ВНа веб интерфейсе доступно ручное управление, 3D модель, редактор программ, логи.
- Исполнитель `FollowJointTrajectory` для MoveIt и программ.

  ros-jazzy-joint-state-publisher-gui ros-jazzy-rviz2 \

```bash
mkdir -p ~/ros2_ws/src

git clone <адрес-репозитория> minipulator
cd ~/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

## Правило udev

Плата на CH340 при каждом подключении может получить другой номер
(`/dev/ttyUSB0`, `/dev/ttyUSB1`), а доступ к порту зависит от группы
`dialout`. Правило даёт постоянное имя `/dev/minipulator` с правами 0666,
поэтому команды запуска и мост не зависят от номера.

Применить нужно один раз после установки пакета, до первого запуска с платой. Если
порт перестал находиться после переподключения, правило стоит проверить.

```bash
sudo cp "$(ros2 pkg prefix minipulator)/share/minipulator/udev/99-minipulator.rules" /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
```

После установки правил плату переткнуть. Без правила мост сам найдёт первый
`ttyUSB*`; если плат несколько, порт лучше указать явно:

```bash
ros2 launch minipulator teleop.launch.py port:=/dev/ttyUSB0
```

## Прошивка

Открыть `firmware/minipulator/minipulator.ino` в Arduino IDE, выбрать плату
**Arduino Nano** (для некоторых плат нужно выбрать загрузчик  **ATmega328P (Old Bootloader)** ), загрузить. Из библиотек нужна только `Servo`.

При включении плата ждёт 1,5 с, подключает сервы по одному (через 250 мс) и
уводит их в стартовую позу.

Протокол (115200 бод, строки ASCII, `\n`):

| Направление | Сообщение | Смысл |
| --- | --- | --- |
| ПК → плата | `T<s1> <s2> <s3> <s4> <s5> <s6> <мс>` | целевые углы серв и время перехода |
| ПК → плата | `P` | пинг |
| плата → ПК | `READY` | загрузка окончена, стартовая поза достигнута |
| плата → ПК | `S<s1> ... <s6>` | текущие углы серв, 20 Гц |
| плата → ПК | `PONG` | ответ на пинг |
| плата → ПК | `E <текст>` | сообщение об ошибке |

## Запуск

Порт занимает мост, поэтому одновременно запускается только один вариант.

### Только модель

```bash
ros2 launch minipulator view.launch.py
```

Запускает `robot_state_publisher`, `joint_state_publisher_gui` и RViz, без реального робота

### Ползунки

```bash
ros2 launch minipulator teleop.launch.py
```

Прямое управление сервами с помощью ползунков, выбранные положения публикуются в `/target_joint_states`, мост двигает сервы и отдаёт
`/joint_states` для RViz. 

### MoveIt в RViz

```bash
ros2 launch minipulator moveit.launch.py execute:=true
```

Запускает `robot_state_publisher`, мост, `move_group` и RViz. С `execute:=true`
добавляется исполнитель траекторий, поэтому работает **Plan → Execute**. Без
него доступно только планирование.

### Веб-интерфейс

```bash
ros2 launch minipulator web.launch.py
# http://127.0.0.1:8080
```

Запускает `robot_state_publisher`, мост, `move_group`, исполнитель и
веб-сервер. Аргументы: `port:=/dev/ttyUSB0`, `web_port:=8081`,
`host:=0.0.0.0` (открывает страницу в сеть; авторизации нет).

Страница и three.js лежат в пакете (`web/vendor`), интернет не нужен.

### Демонстрации

При запущенном MoveIt (`execute:=true`):

```bash
ros2 run minipulator demos --list
ros2 run minipulator demos pick_place
ros2 run minipulator demos hello --speed 0.5 --pause 0.2
```

## Веб-интерфейс

### Программирование робота

Программа — список шагов:

- `pose` — углы поворота звеньев (рад), угол открытия захвата, пауза после достижения точки (сек)
  и скорость (0.1–1.0 от лимитов MoveIt);
- `wait` — отдельная пауза в миллисекундах; робот стоит на месте.

У каждого шага есть имя, его можно менять в списке. `▶` выполняет только этот
шаг, `👁` планирует его без движения и рисует путь запястья, `⧉` дублирует,
`↑`/`↓` меняют порядок, `⟲` заменяет позу текущей, `✕` удаляет. Галочка
«по кругу» повторяет программу до СТОП. Шаг-пауза добавляется кнопкой
«⏸ Пауза».

Программа выполняется через MoveIt `/move_action` (планирование и проверка
столкновений) и исполнитель траекторий. На время выполнения ручное управление
заблокировано.

JSON программы:

```json
{
  "version": 1,
  "name": "pick_place",
  "description": "взять мяч и переставить в сторону",
  "saved": "2026-10-28T18:00:00",
  "steps": [
    {"type": "pose", "name": "pos_1", "joints": [0.0, 0.0, -0.1745, 0.8727, 0.0],
     "gripper": 0.3, "pause": 0.3, "speed": 0.4},
    {"type": "wait", "name": "wait_2", "ms": 1000}
  ]
}
```

## Соглашения по суставам

`joint1`…`joint5` — звенья робота, `gripper_joint` — привод губки захвата. Мост пересчитывает углы
модели в углы серв и обратно:

```
q_rad      = sign * (servo_deg - zero_deg) * pi / 180
servo_deg  = zero_deg + sign * q_rad * 180 / pi
```

`zero_deg = [90, 90, 10, 90, 0, 0]`, `sign = [+1, -1, +1, -1, +1, +1]`,
стартовая поза `q = [0, 0, -0.1745, 0.8727, 0]` → сервы `[90, 90, 0, 40, 0, 0]`.

| Сустав | Нижний предел (рад) | Верхний предел (рад) |
| --- | --- | --- |
| joint1 | -1.5708 | 1.5708 |
| joint2 | -1.5708 | 1.5708 |
| joint3 | -0.1746 | 1.3963 |
| joint4 | -1.5708 | 1.5708 |
| joint5 | 0.0 | 3.1416 |
| gripper_joint | 0.0 | 1.5708 |

Звенья: `base_link` → `link1` … → `link5`; захват крепится к `link5`.
Мировые оси: X вправо, Y от наблюдателя в глубину, Z вверх.

Лимиты MoveIt — `1.0 рад/с` и `3.0 рад/с²` на сустав в
`config/joint_limits.yaml`; мост по умолчанию едет на 60 °/с, прошивка
ограничивает переходы 150 °/с и требует минимальное время хода.

## Безопасность

Рука работает без обратной связи. Заклинившая серва, упёршийся сустав или
отвалившийся провод не обнаруживаются ни одним узлом: `/joint_states`
продолжают показывать скомандованные углы.

## Адаптация под другого робота

Пакет поставляется с размерами, лимитами и калибровкой конкретной руки. Чтобы
подключить другой манипулятор с такой же архитектурой (Arduino + ROS 2,
сервы без обратной связи, другие размеры или URDF), см.
[`instructions/ADAPTING_TO_ANOTHER_ROBOT.md`](instructions/ADAPTING_TO_ANOTHER_ROBOT.md).

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| нет `/dev/minipulator` | правило udev установлено, плата переткнута |
| `Permission denied` на порту | пользователь в группе `dialout`, либо `sudo chmod 666 <порт>` |
| `port busy` | уже работает другой мост: `pkill -f serial_bridge` |
| нет `/joint_states` | мост не запустился, смотреть его вывод |
| MoveIt не строит план | цель вне досягаемости, устаревшее стартовое состояние, столкновение звеньев |
| страница пустая | открыть консоль браузера и проверить `/vendor/three.module.js` |
| IK не находит решение в джойстике | цель вне рабочей зоны или за лимитами суставов |
| программа останавливается с `MoveIt: ошибка` | у позы нет IK-решения или она в столкновении |

## Ограничения

- Нет энкодеров, датчиков усилия и камер.
- URDF собран из коробок и не учитывает инерцию.
- Веб-сервер — инструмент на одного пользователя без авторизации.
